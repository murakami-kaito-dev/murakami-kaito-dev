## 🧗‍♂️ My Released App
### [イワノボリタイ - Bouldering Activity App](https://apps.apple.com/jp/app/%E3%82%A4%E3%83%AF%E3%83%8E%E3%83%9C%E3%83%AA%E3%82%BF%E3%82%A4/id6753177257)
A bouldering activity tracker that allows climbers to discover gyms, share climbing logs, and connect with others in the community.  
Built with **Flutter**, **Firebase**, **Supabase**, and **Google Cloud Platform**.

## 🛠️ Tech Stack
- Flutter / Dart
- TypeScript
- Firebase Authentication  
- Cloud Functions (Node.js)  
- PostgreSQL on Cloud SQL/Supabase
